Base URL: {{ base }} · JSON in, JSON out · interactive reference: Swagger UI

Endpoints

Method & pathPurpose
POST/api/infoDetect media type and list genuine options. Body {"url", "playlist"?}. Returns type = video | playlist | gallery and media_type = video, audio, photo, carousel, album, mixed, playlist.
POST/api/formatsEvery raw format of a video (resolution, codecs, bitrates, size, protocol).
POST/api/downloadStart a job. kind = video (quality = short side, e.g. 2160, or best), audio (quality = mp3-320, m4a, opus, flac, wav…), or gallery (items: 1-based indexes, empty = all → ZIP).
GET/api/jobs/{id} · GET/api/jobs?ids=a,bJob status, progress, speed, ETA, output media (verified resolution/codecs) and file_url.
POST/api/jobs/{id}/pause|resume|retry|cancelDownload manager actions. Paused jobs keep partial data; retry restarts failed or cancelled jobs.
DELETE/api/jobs/{id}Cancel and remove a job and its file.
GET/api/jobs/{id}/fileDownload the finished file (supports HTTP Range).
POST/api/subtitlesSubtitles as SRT or VTT.
POST/api/tools/uploadRaw-body upload (header X-Filename), max {{ settings.max_upload_mb }} MB → upload_id.
POST/api/tools/probe · POST/api/tools/convertffprobe metadata of an upload · convert it to mp3-320/256/192/128, m4a, wav, flac, opus or original (returns a job).
GET/api/health · GET/api/configService health and public limits.

Example: genuine 4K video

curl -s -X POST {{ base }}/api/info -H 'content-type: application/json' \
  -d '{"url": "https://www.youtube.com/watch?v=aqz-KE-bpKQ"}' | jq '.video[] | {id, label, original}'

curl -s -X POST {{ base }}/api/download -H 'content-type: application/json' \
  -d '{"url": "https://www.youtube.com/watch?v=aqz-KE-bpKQ", "kind": "video", "quality": "2160"}'
# → {"id": "3f2c…", "status": "queued", …}

curl -s {{ base }}/api/jobs/3f2c… | jq '{status, progress, media}'
# when status == "finished": media = {"width": 3840, "height": 2160, "vcodec": "VP9", …}
curl -L -o video.mp4 {{ base }}/api/jobs/3f2c…/file

If the requested quality isn't available from the source, the job fails with error_code: "quality_unavailable" before anything is downloaded — MediaGrab never silently downgrades or upscales.

Example: all photos of a post as ZIP

curl -s -X POST {{ base }}/api/info -H 'content-type: application/json' \
  -d '{"url": "https://www.instagram.com/p/BoHk1haB5tM/"}' | jq '{media_type, count, items: [.items[] | {index, type, label}]}'

curl -s -X POST {{ base }}/api/download -H 'content-type: application/json' \
  -d '{"url": "https://www.instagram.com/p/BoHk1haB5tM/", "kind": "gallery", "items": []}'

Example: convert your own file

curl -s -X POST {{ base }}/api/tools/upload -H 'X-Filename: clip.mp4' --data-binary @clip.mp4
# → {"upload_id": "…24 hex…", …}
curl -s -X POST {{ base }}/api/tools/convert -H 'content-type: application/json' \
  -d '{"upload_id": "…", "target": "mp3-320"}'

Errors

Errors are JSON: {"error": "human readable message", "code": "machine_code"}. Common codes: invalid_url, unsupported, no_video, login_required, private, quality_unavailable, bot_check, yt_blocked, rate_limited, too_large, ffmpeg_failed, incomplete.
